# Dilkhas Basheer A — Portfolio Website

A responsive multi-page portfolio website created for the HTML5 + External CSS assignment.

## Pages
1. Home — `index.html`
2. About Me — `about.html`
3. Achievements — `achievements.html`
4. My Gallery — `gallery.html`
5. Contact Me — `contact.html`

## Technologies
- HTML5
- External CSS3
- JavaScript for mobile navigation and demo form
- Google Fonts

## Before final submission
- Replace the six gallery placeholders with your own photos.
- Add exact project names, certificate names and awards if you have them.
- Add your GitHub/LinkedIn links if required.
- Test every navigation link on mobile and desktop.

## GitHub Pages
Keep `index.html` in the root of the repository. Then enable GitHub Pages from:
Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
